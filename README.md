## SONIC MANIA ARCHIPELAGO

SETUP (assuming you already know how to install custom worlds):

Download Release.zip and extract it

Copy Data.rsdk from the root folder of your legally obtained Sonic Mania Plus and put it next to RSDKv5U.exe

Edit connectioninfo.txt with the server name/port, slot name and password on separate lines, in that order.

Launch RSDKv5U.exe to connect and run the game
